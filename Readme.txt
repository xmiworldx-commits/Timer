TIMER - секундомер с таймером
==============================

Запуск
------
1. Готовое приложение: двойной клик по Timer.exe
2. Из исходников: python stopwatch_timer.py
   (нужен Python 3; внешних библиотек не требуется)

Возможности
-----------
- Секундомер: старт/пауза/сброс, отображение минут:секунды.сотые.
- Таймер: установка интервала, обратный отсчёт.
- Звуковой сигнал по окончании таймера: двухтональный (880/1175 Гц),
  повторяется до нажатия Start или Reset.
- Окно фиксированного размера, тёмная тема.

Сборка exe
----------
python -m PyInstaller --onefile --noconsole --name Timer stopwatch_timer.py
